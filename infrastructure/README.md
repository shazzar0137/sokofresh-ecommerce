# Infrastructure

Plans and, later, configuration for running SokoFresh.

- `development/`, `testing/`, `staging/`, `production/`: one folder per environment.
- `deployment/`, `containers/`, `ci-cd/`: how code is built and shipped.
- `monitoring/`, `logging/`, `backup/`, `networking/`: operating the live system.

Empty until hosting and infrastructure are chosen. No real credentials or production secrets may be stored here.
