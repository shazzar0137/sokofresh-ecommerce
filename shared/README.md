# Shared

The agreements between frontend and backend.

| Path | Holds |
|---|---|
| `contracts/` | API contracts: endpoints, requests, responses, error formats |
| `schemas/` | Data structure definitions both sides validate against |
| `constants/` | Values both sides must agree on (order statuses, currency code KES) |
| `test-fixtures/` | Sample data used by tests in both applications |
| `documentation/` | How contracts are versioned and changed |

A contract change affects both applications. It must be documented, agreed and versioned before either side implements it. The contract is OpenAPI, generated by drf-spectacular from the backend and committed to `contracts/openapi.yaml`; CI fails if it drifts (ADR-0004, ADR-0011). `test-fixtures/` will hold the shared phone-number test list used by both apps.
