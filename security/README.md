# Security

Security design and verification work. Each subfolder holds the plans, decisions and checklists for one area (threat model, authentication, authorization, sessions, input validation, API security, data protection, payment security, dependency security, secrets, security testing, incident response).

The overall plan is in `../docs/security/SECURITY_PLANNING_OUTLINE.md`. Code that implements security controls lives in the applications (e.g. `backend/src/security/`), not here.
